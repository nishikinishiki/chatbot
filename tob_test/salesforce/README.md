# tob_test/salesforce

本番 `/tob/salesforce/` のコードを一切変更せずに作成した、独立したレイアウト検証用ページです。

## 表示
- デスクトップ：左に独立スクロールする1枚画像、右に一括入力フォーム（右側も高さを超えた場合はスクロール）。
- モバイル：画像→フォームの縦積み。
- 姓名、電話番号、メールアドレス：HTMLのautocomplete属性でブラウザ補完に対応。
- 年収、関心テーマ、投資経験、年齢：選択ボタンで回答。
- 2段階目：面談希望日時の第1希望・第2希望を入力。
- 選択肢のvalueは従来の `tob/salesforce/js/questions.js` に合わせています。

## 大切な注意
- **テスト専用**です。GAS送信・GTM読み込みは有効化していません。入力情報はサーバー送信されません。
- 添付画像のGitHubへの取り込みは未実施です。現在は既存の `/common/images/Salesforce_BN.jpg` を仮表示しています。掲載画像を変更するときは `index.html` 内の `.visual-image` のsrcを書き換えてください。
- 本番送信を有効にする場合は、現行GASの入力キー、`chat_form_submission_success`、`lead_attributes_ready` のGTMイベント、通信失敗時の挙動・個人情報の取扱いを別途検証してください。
- 第2段階の「その他時間」は自由入力欄を表示して入力可能です。
- 実装対象ファイルはこのフォルダ内のみです。本番フォルダのHTML/JS/CSSには変更ありません。
